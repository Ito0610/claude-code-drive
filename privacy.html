プライバシーポリシー

対象: claude-code-drive（作成者が個人で使う Google ドライブ連携ツール）

使う情報

ログインした Google アカウントの Google ドライブにあるファイルとフォルダだけを扱います。

使い道

フォルダの一覧を見ることと、ファイルをアップロードすることだけに使います。

保存と共有

  • ログイン情報（トークン）は、作成者のパソコンの中にだけ保存します。
  • Google ドライブのデータを、作成者以外のサーバーや第三者に送ることはありません。
  • 広告や分析には使いません。

Google API サービスのユーザーデータに関するポリシー

Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

English

claude-code-drive only accesses files and folders in the signed-in user's own Google Drive. It uses them only to list folders and upload files. Tokens are stored only on the owner's computer. No data is sent to any other server or third party, and no data is used for advertising or analytics. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
